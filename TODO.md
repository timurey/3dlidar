## Железо

### [ ] Тест: OPi 5 Plus → OPi 3B (RK3566)

Текущая схема: 1x GbE (VLP-16) + WiFi (LAN) — dual GbE не используется.
OPi 3B (~$35-50) покрывает все требования Pulse при меньшей цене.

**Методика:** эмулировать A55-only на текущей плате — отключить A76 ядра (0–3):

```bash
sudo bash -c 'for i in 0 1 2 3; do echo 0 > /sys/devices/system/cpu/cpu$i/online; done'
```

Запустить обычный сценарий: запись скана + preview в браузере + экспорт E57.

| Метрика                 | Инструмент                        | Порог "ок"         |
| ----------------------- | --------------------------------- | ------------------ |
| CPU загрузка при записи | `htop`                            | < 50% на A55 ядрах |
| Частота VLP-16          | `ros2 topic hz /velodyne_points`  | стабильно 10 Hz    |
| Время deskew preview    | браузер / `X-Compute-S` заголовок | < 1.0 s            |
| Пропуски в bag          | `ros2 bag info` после записи      | 0 dropped          |

Ожидания: preview ~0.4–0.7 s на A55 (сейчас ~0.17 s на A76) — приемлемо.

Вернуть A76 после теста:

```bash
sudo bash -c 'for i in 0 1 2 3; do echo 1 > /sys/devices/system/cpu/cpu$i/online; done'
```
